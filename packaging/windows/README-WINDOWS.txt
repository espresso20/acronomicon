===============================================================================
  THE ACRONOMICON — The Bible of Cloud Tech Acronyms (Windows Package v1.0.0)
===============================================================================

INCLUDED IN THIS PACKAGE:
  1. acronomicon-setup.exe    - One-click Windows Setup Wizard (Installs to
                                %LOCALAPPDATA%\Programs\Acronomicon, adds
                                'acronomicon' to your Windows PATH, creates
                                Start Menu & Desktop shortcuts, and registers
                                in Windows Installed Apps).
  2. acronomicon.exe          - Standalone portable CLI & interactive binary
                                (no installation required — run directly!).
  3. Launch Acronomicon.bat   - Double-click to open the interactive REPL.
  4. install.ps1              - PowerShell installer script (alternative).
  5. uninstall.ps1            - PowerShell uninstaller script.

QUICK START (COMMAND LINE):
  acronomicon                 Launch interactive full-color mode (acronomicon>)
  acronomicon k8s             Look up an acronym card (e.g. k8s, vpc, ebpf, s3)
  acronomicon search zero     Search across 400+ cloud tech acronyms
  acronomicon list a          List all acronyms starting with 'A'
  acronomicon category        Browse by cloud category
  acronomicon random          Show a random Acronomicon Verse of the Day
  acronomicon quiz            Play the interactive cloud acronym quiz
  acronomicon stats           View database charts & statistics
===============================================================================
