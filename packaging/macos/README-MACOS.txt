===============================================================================
  THE ACRONOMICON — The Bible of Cloud Tech Acronyms (macOS Universal v1.0.0)
===============================================================================

ARCHITECTURE:
  Universal Binary (Apple Silicon arm64 + Intel x86_64)

INCLUDED IN THIS PACKAGE:
  1. acronomicon-macos-universal.pkg  - Native macOS Installer (.pkg) that
                                        installs /usr/local/bin/acronomicon
                                        and /Applications/Acronomicon.app.
  2. Acronomicon.app                  - macOS Application bundle (double-click
                                        or open from Spotlight to launch in
                                        macOS Terminal).
  3. acronomicon                      - Standalone Universal CLI binary.
  4. Install Acronomicon.command      - Double-click user-local installer
                                        (no sudo required; installs to
                                        ~/.local/bin and ~/Applications).
  5. Uninstall Acronomicon.command    - Double-click uninstaller.

QUICK START (TERMINAL):
  acronomicon                 Launch interactive full-color mode (acronomicon>)
  acronomicon k8s             Look up an acronym card (e.g. k8s, vpc, ebpf, s3)
  acronomicon search zero     Search across 400+ cloud tech acronyms
  acronomicon list a          List all acronyms starting with 'A'
  acronomicon category        Browse by cloud category
  acronomicon random          Show a random Acronomicon Verse of the Day
  acronomicon quiz            Play the interactive cloud acronym quiz
  acronomicon stats           View database charts & statistics
===============================================================================
