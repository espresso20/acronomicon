Acronomicon is Installed!

You can now launch Acronomicon from /Applications/Acronomicon.app or open any macOS Terminal window and run:

acronomicon              # Interactive full-color REPL
acronomicon k8s          # Look up any cloud acronym card
acronomicon search zero  # Search across 400+ acronyms
acronomicon random       # Random Verse of the Day
acronomicon quiz         # Interactive multiple-choice quiz
